# Explainer Video Script: Projects & Reviews Integration (Dashboard v2.4)

**Length:** ~4 minutes  
**Feature set:** Active Projects, Projects to Review, next actions, progress comments, Project dialog, two-way sync with Projects & Reviews

## Setup & B-roll (before you record)

**Prerequisites**
- Projects & Reviews plugin installed and set up (project notes with `@review(...)`, next-action markers as you define them, at least one Sequential project if you want to demo that filter)
- Dashboard v2.4 with both project sections enabled: **Active Projects** and **Projects to Review**
- A Perspective that includes your demo project folders (or rely on Projects & Reviews folder settings)
- Optional: Projects & Reviews list/window open in the background to show two-way sync

**Demo data to prepare**
- 3–5 **active** projects (not paused / completed / cancelled), each with a clear title
- At least two with a visible **next action** task
- At least one with a recent **progress** comment (Projects & Reviews style)
- 1–2 projects **due for review** (so they appear under Projects to Review)
- One project you can safely complete/cancel a next action on during the take (have a second next action ready so round-trip replacement is obvious)

**Recommended settings for the take**
- Turn on **Active Projects** and **Projects to Review**
- For one cut: enable **Show only projects with next actions**, then toggle it off to show the fuller list
- Keep the Dashboard refresh visible (manual refresh or wait for auto-update after an action)

**B-roll shot list (gather these clips)**
- Dashboard overview with both project sections visible
- Close-up of an Active Projects row: project title + next action + progress comment
- Same for a Projects to Review row
- Completing a next action in Active Projects → section updates with a new next action
- Cancelling a next action (brief)
- Opening the Project dialog: **Start**, latest progress, **Add** progress, Finish Review / Skip
- Side-by-side or cut: change in Projects & Reviews → Dashboard updates (and the reverse after a Dashboard action)
- Settings: Active Projects section + “Show only projects with next actions”

**On-screen text cards (optional)**
- “Dashboard v2.4 · Projects & Reviews”
- “Active Projects” / “Projects to Review”
- “Next actions stay in sync”
- “Display + actions — same source of truth”

## Hook

Jonathan Clark here with another quick explainer for a small but useful new feature in Dashboard plugin v2.4.

[UX] _Wide shot of Dashboard; zoom into the two project sections._

If you run projects in NotePlan with the Projects & Reviews plugin, Dashboard v2.4 pulls that world onto one screen -- what’s active, what’s due for review, and what to do next -- without leaving your daily view.

## Two sections, clearer jobs

[UX] _Label callouts on **Active Projects** and **Projects to Review**. Briefly flash the old “Projects” name if you have a before still; otherwise just name the rename._

There are now two complementary sections.  
**Active Projects** lists your open projects from Projects & Reviews -- not completed, cancelled, or paused -- and shows the first next action where one exists.  
The older Projects section is renamed **Projects to Review**: that’s the queue of reviews that are due, still powered by the same plugin lists.  
Same source of truth; two jobs on the Dashboard.

## What you see on each row

[UX] _Slow pan down Active Projects rows; highlight next action under the title, then a progress comment. Cut to Projects to Review showing the same kind of detail._

Each project row can show more than a title.  
You’ll see the latest **progress** comment when there is one, and the current **next action** as defined in Projects & Reviews -- with the same rich display as other Dashboard tasks: tags, mentions, links, dates.  
So you can scan status and the next step without opening every note.

## Act on next actions

[UX] _Click to complete a next action in Active Projects; wait for refresh; new next action appears. Optionally cancel one on another project._

And those next actions aren’t just for reading.  
In both project sections you can **complete** or **cancel** them like any other Dashboard item.  
In **Active Projects**, completing a next action round-trips to the Projects plugin: if there’s another next action waiting, Dashboard brings it in.  
Your project list and your Dashboard stay aligned as you work.

## Project dialog: start review and progress

[UX] _Open the Project dialog from a row. Point out **Start**, latest progress, **Add**, then Finish Review / Skip as a quick sweep._

Click into a project for the full dialog.  
**Start** opens the note so you can begin a review. You’ll also see the latest progress comment right there, and you can **Add** a new one without hunting through menus.  
Finish Review, Skip, Pause, Complete, Cancel -- the same moves you know from Projects & Reviews -- still live here. Dashboard is a control surface, not a separate silo.

## Filter and sync

[UX] _Settings → Active Projects → toggle **Show only projects with next actions**; cut back to a shorter list. Then a quick two-way sync beat: finish something in one plugin, watch the other update._

Prefer a tighter Active Projects list? Turn on **Show only projects with next actions** -- Sequential projects with open work are included too.  
And under the hood, sync with Projects & Reviews is stronger both ways: updates from the project lists flow into Dashboard, and actions you take here feed back. One workflow, two windows if you want them.

## Close

[UX] _Pull back to full Dashboard with both sections. End card: “Dashboard v2.4 · Projects & Reviews integration”._

Active work, reviews due, next actions, and progress -- all on the Dashboard, kept in step with Projects & Reviews. That’s the Projects integration in Dashboard v2.4.
